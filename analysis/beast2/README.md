# BEAST2 Molecular Clock Analyses — KapK Methanoflorentales

All analyses use the no-deconvolution (nodec) codon alignment of 79 Methanoflorentales taxa.

**ancient_consensus** = KapK-anc: ancient genome recovered from 2 Ma permafrost,
Kap København Formation, N Greenland.

**s17_ancient_relative** = living Methanoflorentales from S17 bog incubation experiment;
sister taxon to ancient_consensus in the species-level clade.

The core result: ancient_consensus accumulated only ~24 kyr of molecular evolution
over its 2 Ma of geological burial — an ~82-fold suppression of the effective
substitution rate compared to background Methanoflorentales (stasis).

## Software

- BEAST2 v2.7.7
- MODEL_SELECTION v1.6.2 (path sampling)
- flc v1.2.0 (FlexibleLocalClockModel — for 2clock/3clock analyses)
- BEAGLE v3 (GPU/CPU acceleration)

Install BEAST2 packages via Package Manager or:
```bash
beast -packagepath /path/to/beast2/packages -add MODEL_SELECTION flc
```

## Input Alignment

The codon alignment is generated by the `wf/stasis/` pipeline (Parts D–F):
- 41 universal archaeal markers, MAFFT linsi + BMGE BLOSUM30 trimming
- Back-translated to codons (`scripts/back_translate.py`)
- Concatenated (`scripts/concatenate_codon.py`)
- 79 Methanoflorentales taxa: 77 reference + ancient_consensus + s17_ancient_relative
- `include_modern_consensus: false` — modern_consensus excluded (deconvolution artifact)

## XML Generation

XMLs in `xmls/` were generated by:
- `wf/stasis/scripts/create_beast2_xml.py` — tipdating, freedate, fixed-age, 2clock, 3clock, ucld
- `wf/stasis/scripts/make_pathsampling_xml.py` — path sampling wrappers (ps_*.xml)

To regenerate:
```bash
python wf/stasis/scripts/create_beast2_xml.py --config wf/stasis/config.yaml
python wf/stasis/scripts/make_pathsampling_xml.py
```

## Analyses

### 1. Strict Clock Tipdating — `codon_tipdating_nodec.xml`

KapK-anc (ancient_consensus) tip date fixed at **2 Ma BP** (uniform prior ±0.05 Ma).
Strict clock. Birth-death serial sampling (BDSS) tree prior.
Clock rate prior: LogNormal(M=5×10⁻⁹, S=1.0).

```bash
beast -beagle_GPU -threads 8 -seed 42 -overwrite \
    xmls/codon_tipdating_nodec.xml
treeannotator -burnin 10 -height mean \
    codon_tipdating_nodec.trees results/codon_tipdating_mcc.tree
```

**Results** (`results/codon_tipdating_mcc.tree`):
| Parameter | Value |
|-----------|-------|
| Background clock rate | 1.10×10⁻⁸ subst/site/yr |
| HPD95 (clock rate) | 9.4–12.8×10⁻⁹ |
| KapK-anc branch (MCC median) | 24,354 yr |
| Fold stasis (s17 lineage) | 2,000,000 / 24,354 ≈ **82×** |

### 2. Freedate — `codon_freedate_nodec.xml`

KapK-anc tip date as a **free parameter** (no geological prior).
Uniform(1 Ma, 5 Ma) prior on tip date. Strict clock, BDSS.
Two replicate runs (seed 11111 and seed 99999) for reproducibility.

```bash
# Rep 3
beast -beagle_CPU -beagle_SSE -threads 32 -seed 11111 -overwrite \
    xmls/codon_freedate_nodec.xml
treeannotator -burnin 10 -height mean \
    codon_freedate_nodec.trees results/codon_freedate_rep3_mcc.tree

# Rep 4
beast -beagle_CPU -beagle_SSE -threads 32 -seed 99999 -overwrite \
    xmls/codon_freedate_nodec.xml
treeannotator -burnin 10 -height mean \
    codon_freedate_nodec.trees results/codon_freedate_rep4_mcc.tree
```

**Results** (`results/codon_freedate_rep3_mcc.tree`, `results/codon_freedate_rep4_mcc.tree`):
| Rep | Posterior tip age (KapK-anc) | KapK-anc branch (MCC) | ESS |
|-----|------------------------------|----------------------|-----|
| rep3 (seed 11111) | 1.937 Ma | 33,485 yr | — |
| rep4 (seed 99999) | 1.996 Ma | 33,066 yr | 5358 |

Interpretation: molecular data alone prefer ~2 Ma for KapK-anc; consistent with
independent geological age.

### 3. Freedate Prior Sensitivity — `codon_freedate_prioronly_nodec.xml`

Same as freedate but with `sampleFromPrior=true`. Tests whether posterior is
data-driven or prior-driven.
Geological prior: Uniform(1.87 Ma, 2.70 Ma) on KapK-anc tip date.

```bash
beast -beagle_CPU -threads 8 -seed 42 -overwrite \
    xmls/codon_freedate_prioronly_nodec.xml
```

**Results**: Prior range 1.876–2.594 Ma (0.72 Ma wide); posterior (freedate rep4)
range ~1.87–2.06 Ma (0.19 Ma wide) — posterior is substantially narrower and
shifted, confirming the molecular data are actively informing the age estimate.

### 4. Fixed-Age Sensitivity — `codon_tipdating_0Ma_nodec.xml`, etc.

KapK-anc tip date fixed at 0, 0.5, 1, and 2 Ma (4 analyses).
Used for Bayes factor comparison via path sampling (see below).

```bash
for age in 0Ma 0.5Ma 1Ma; do
    beast -beagle_CPU -threads 8 -seed 42 -overwrite \
        xmls/codon_tipdating_${age}_nodec.xml
done
```

### 5. Path Sampling — `ps_0Ma.xml`, `ps_0.5Ma.xml`, `ps_1Ma.xml`, `ps_2Ma.xml`

Marginal likelihood estimation for the four fixed-age models.
64 steps, α=0.3, 2M chain per step, preBurnin=1M, burnIn=50%.

```bash
beast -beagle_CPU -threads 8 -seed 42 xmls/ps_2Ma.xml
# ... repeat for ps_0Ma.xml, ps_0.5Ma.xml, ps_1Ma.xml
```

**Results** (once all runs complete — see `results/path_sampling_marginal_likelihoods.tsv`):
| Model | log ML | 2×log BF vs 2Ma |
|-------|--------|-----------------|
| 0 Ma  | TBD    | TBD             |
| 0.5 Ma | TBD  | TBD             |
| 1 Ma  | TBD    | TBD             |
| 2 Ma  | **−92442.52** | 0 (reference) |

Bayes factor interpretation: 2×log BF > 10 = decisive evidence.

### 6. Broad Prior Sensitivity — `codon_broadprior_nodec.xml`

Same as tipdating but with wider clock rate prior (S=2.0 instead of S=1.0).
Tests sensitivity to clock rate prior specification.

### 7. UCLD Relaxed Clock — `codon_ucld_tipdating_nodec.xml`

UCRelaxedClockModel (uncorrelated lognormal). KapK-anc fixed at 2 Ma.
Tests whether strict clock assumption biases the stasis estimate.
Expected: ucldSD >> 1 (rate heterogeneity; ancient branch ~100× below mean).

```bash
beast -beagle_GPU -threads 8 -seed 42 -overwrite \
    xmls/codon_ucld_tipdating_nodec.xml
treeannotator -burnin 10 -height mean \
    codon_ucld_tipdating_nodec.trees results/codon_ucld_tipdating_mcc.tree
```

### 8. 2-Clock Stasis — `codon_2clock_stasis_nodec.xml`

FlexibleLocalClockModel (flc package). Two rates:
- `clockRateBg`: background rate (all branches except KapK clade)
- `clockRateMod`: stasis rate (KapK clade: ancient_consensus + s17_ancient_relative)

Prior: clockRateBg ~ LogN(M=1.1×10⁻⁸, S=0.2) [tight, anchored to strict clock HPD];
clockRateMod ~ LogN(M=10⁻⁹, S=2.0) [broad, allows stasis rates].

Hypothesis: if KapK-anc age is correct, both KapK branches should show suppressed rates.

```bash
beast -beagle_CPU -threads 8 -seed 42 -overwrite \
    xmls/codon_2clock_stasis_nodec.xml
```

### 9. 3-Clock Models — `codon_3clock_fixed_nodec.xml`, `codon_3clock_heavyop_nodec.xml`, `codon_3clock_stasis_nodec.xml`

Three separate rates: background, ancient (ancient_consensus only), modern stasis (s17).
All three variants failed to converge: single ancient_consensus tip provides
insufficient data to estimate rateAnc independently (clockRateAnc acceptance ~6.8%).
All three rates converge to identical values (~2–4×10⁻⁸).
**These analyses are included for completeness; results should not be interpreted.**

## Interpretation Summary

The strict clock tipdating analysis is the primary result. The freedate analyses
serve as an independent cross-check: molecular sequences alone (no geological prior)
recover KapK-anc tip date ~1.94–2.0 Ma, consistent with the geological age.

**Stasis quantification**: The KapK-anc branch accumulated ~24 kyr of molecular
evolution over 2 Ma of burial. The living sister lineage (s17_ancient_relative) has
the same substitutional distance from their LCA — but that ~24 kyr of change spans
2 Ma of real time → effective rate ~1.34×10⁻¹⁰ subst/site/yr vs background
~1.1×10⁻⁸ → **~82-fold genomic stasis**.
