# KapK Stasis Workflow

Snakemake pipeline for the KapK ancient Methanoflorentales analysis.
Covers Parts A–H: binning → resolve → QC → deconvolution → phylogenomics → BEAST2 → pN/pS → SNP tree.

## Dependencies

### Software
- [AMBER](https://github.com/MicrobialDarkMatter/amber) — metagenomic binner for ancient DNA
- [BEAST2 v2.7.7](https://beast2.org) + packages: MODEL_SELECTION v1.6.2, flc v1.2.0
- [IQ-TREE2](http://www.iqtree.org)
- [MAFFT](https://mafft.cbrc.jp/alignment/software/)
- [BMGE](https://research.pasteur.fr/en/software/bmge/)

## Configuration

`config.yaml` — main configuration (all `<SET_THIS>` paths must be set).

`config_with_dec.yaml` — variant including `modern_consensus` (modern KapK bin from
HMW-DNA size-selected reads); used for deconvolution sensitivity checks.

Key parameters:
```yaml
skip_binning: true           # set false to run AMBER from scratch
skip_mapping: true           # set false to run bowtie2 + filterBAM
include_modern_consensus: false   # true → config_with_dec.yaml
sample_age: 2000000          # KapK ancient_consensus tip date: 2 Ma BP
```

## Pipeline Overview

### Part 0: Read Mapping (optional)
`skip_mapping: true` — skip if you have the pre-built BAM.
`skip_mapping: false` — runs bowtie2 (k=1000) + filterBAM EM reassignment.

### Part A: AMBER Binning
Metagenomic binning optimised for ancient DNA.
Best configuration: encoder_seed=42, leiden_seed=1006, resolution=5.0, bandwidth=0.2.
Set `skip_binning: false` to run from scratch.

### Part A (resolve): Bin Consensus
`amber resolve` merges results from multiple AMBER runs (n_reps=3) using
co-binning affinity consensus with SCG-guided resolution sweep.

### Part B: QC — CheckM2, GUNC, GTDB-Tk
MQ filter: completeness ≥ 50%, contamination ≤ 10%.
Ancient bin selection: GTDB-Tk clade contains "Bog-38", completeness ≥ 90%, contamination ≤ 5%.

### Part C: Deconvolution
`filterBAM` EM deconvolution separates ancient signal from modern contamination.
Output: `ancient_consensus` (ancient KapK genome) and `modern_consensus` (living cell signal).

### Part D: Marker Extraction + Alignment
41 universal archaeal markers (DNGNGWU + COG ribosomal proteins).
HMM search → Prodigal gene prediction → MAFFT linsi → BMGE BLOSUM30 trimming.
Codon alignment via back-translation.

### Part E: BEAST2 Molecular Clock
XML generation scripts:
- `scripts/create_beast2_xml.py` — strict clock tipdating XML
- `scripts/create_beast2_snp_xml.py` — SNP tree XML
- `scripts/make_pathsampling_xml.py` — path sampling (marginal likelihood) XMLs

Pre-generated XMLs in `../analysis/beast2/xmls/`.
See `../analysis/beast2/README.md` for full description of all analyses.

### Part F: IQ-TREE Phylogenomics
Concatenated codon alignment → IQ-TREE2 (GTR+G4, 1000 bootstrap + 1000 alrt, 100 sCF quartets).
SNP tree: NUCmer pairwise alignment → SNP matrix → IQ-TREE2 (GTR+ASC+G4).

### Part G: pN/pS
`scripts/compute_pnps.py` + `scripts/genome_pnps.py` — per-gene and genome-wide pN/pS ratios.
`scripts/validate_stasis.py` — stasis validation tests.

### Part H: Incubation Comparison
dRep dereplication of incubation bins vs KapK + S17 reference.
Read mapping of S17 incubation reads to dereplicated bins.

## Running

```bash
# Dry run
snakemake --snakefile Snakefile --configfile config.yaml -n

# Full run (SLURM cluster)
snakemake --snakefile Snakefile --configfile config.yaml \
    --profile profile/ --jobs 100

# Local run
snakemake --snakefile Snakefile --configfile config.yaml \
    --profile profile_local/ --cores 16
```

SLURM profile in `profile/`, local profile in `profile_local/`.
